Questão 1 — Estação de observação do céu (5,0 pontos)

O que fazer

Uma equipe de estudantes criou uma página para divulgar uma noite de observação astronômica. Use o HTML-base apresentado no exemplo abaixo e crie, na mesma pasta, um arquivo chamado estilo.css. Vincule esse arquivo ao HTML e faça nele todas as alterações visuais pedidas a seguir. Não mude os textos nem acrescente elementos ao HTML.

  1. Página inteira: defina Arial como fonte principal, uma cor escura para os textos e uma cor clara para o fundo da página. Use as propriedades font-family, color e background-color.
  2. Cabeçalho: aplique uma cor de fundo escura, texto claro, borda e alinhamento centralizado. Use background-color, color, border e text-align.
  3. Título principal: escolha uma fonte diferente da fonte dos parágrafos e aumente o tamanho do título com font-family e font-size.
  4. Área do conteúdo: aplique uma cor de fundo clara, uma borda e espaço interno para separar o texto das bordas. Use background-color, border e padding.
  5. Imagem: escolha uma largura adequada e coloque uma borda. Salvem uma imagem na pasta do projeto e atualizem o nome no atributo src, se necessário.
  6. Parágrafos: defina a cor do texto e o tamanho da fonte. A regra para p será aplicada aos parágrafos da página, inclusive ao convite final.
  7. Rodapé: aplique cor de fundo, cor de texto, borda e alinhamento centralizado.

Entrega: o HTML fornecido, a imagem utilizada e o arquivo estilo.css. Confiram que a folha externa está vinculada e que a imagem aparece no navegador.

Use somente propriedades simples estudadas em aula: fonte, tamanho da fonte, cor do texto, cor de fundo, borda, alinhamento, margem e espaço interno. Escolham cores e espessuras de borda que deixem os textos fáceis de ler.

Exemplo de referência — código base e resultado

Este exemplo mostra como reutilizar a estrutura HTML, colocar uma imagem e alterar a aparência por meio de um CSS externo. A prévia mostra apenas uma possibilidade de resultado. A dupla escreverá todo o CSS.

HTML · index.html (modelo da Questão 1)
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Noite de Observação</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <header>
    <h1>Olhos no Universo</h1>
    <p>Uma noite para descobrir o céu</p>
  </header>
  <main>
    <h2>Convite à observação</h2>
    <img src="ceu.jpg" alt="Céu estrelado sobre a cidade">
    <p>Na sexta-feira, nossa turma vai observar a Lua,
    identificar constelações e conversar sobre os planetas.</p>
    <p>Traga sua curiosidade e chegue às 19h!</p>
  </main>
  <footer>Projeto de Ciências · Turma INFO1</footer>
</body>
</html>

Questão 2 — Guia de trilhas e cachoeiras do Piauí (5,0 pontos)

Enunciado

Crie um pequeno site para apresentar destinos de natureza do Piauí. A página inicial será um guia com uma breve apresentação, uma imagem de destaque e links para duas páginas de destino. Escolham duas trilhas, cachoeiras ou parques para apresentar.

  • Crie uma pasta chamada guia-piaui e dentro dela a página inicial index.html.
  • Crie também duas páginas HTML para os destinos escolhidos. Os nomes podem ser, por exemplo, destino1.html e destino2.html.
  • A página inicial deve conter título do site, texto de apresentação, uma imagem, uma lista com dois destinos e links para as respectivas páginas.
  • Em cada página de destino, incluam nome do lugar, imagem, localização, descrição curta e um link para voltar à página inicial.
  • O modelo fornecido abaixo contém somente a primeira página. Criem as duas páginas de destino por conta própria.
  • Confiram que os links abrem as páginas corretas e que o link de retorno de cada destino leva ao index.html.
guia-piaui/ index.html destino1.html destino2.html imagens/ destaque.jpg destino1.jpg destino2.jpg
Salvem as imagens na pasta imagens e usem caminhos relativos, como imagens/destaque.jpg. Para voltar das páginas de destino, o link pode ser index.html, pois todos os arquivos ficam na mesma pasta.
Único modelo HTML fornecido · index.html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Guia de Natureza do Piauí</title>
</head>
<body>
  <header>
    <h1>Trilhas e Cachoeiras do Piauí</h1>
    <p>Conheça lugares para explorar a natureza.</p>
  </header>

  <main>
    <h2>Descubra seu próximo passeio</h2>
    <p>Este guia reúne destinos de natureza do nosso estado.
    Escolha um lugar, conheça um pouco sobre ele e planeje sua visita.</p>

    <img src="imagens/destaque.jpg"
         alt="Paisagem natural do Piauí" width="400">

    <h2>Destinos do guia</h2>
    <ul>
      <li><a href="destino1.html">Nome do primeiro destino</a></li>
      <li><a href="destino2.html">Nome do segundo destino</a></li>
    </ul>
  </main>

  <footer>
    <p>Guia criado por: nomes da dupla</p>
  </footer>
</body>
</html>
